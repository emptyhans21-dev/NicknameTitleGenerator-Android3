# NicknameTitleGenerator Android

架空VTuber名、ペンネーム、二つ名、架空料理名、漢字シャッフル名を10個ずつ生成するAndroidアプリです。

## 機能

- 生成結果を10連表示
- 「月・夜」「自然」「幻想」「創作」を必須要素として指定
- 必須要素を名前内・前・中央・後ろへ配置
- 結果を長押ししてコピー
- 通信・広告・権限要求なし

## APKの入手

GitHubの **Actions** → 最新の **Build Android APK** → **Artifacts** から `NicknameTitleGenerator-debug` をダウンロードしてください。ZIPを展開するとAPKがあります。

## ローカルビルド

Android Studioで開き、`app` をビルドしてください。JDK 17 / Android SDK 35を使用します。
